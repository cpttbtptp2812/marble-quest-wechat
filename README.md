# Marble Quest · 微信小游戏

一款以弹珠为武器的魔法物理冒险原型。玩家从双炮台发射不同属性的弹珠，可以在飞行中点击定身，再用另一颗弹珠主动撞击，触发元素反应。

> 当前阶段：可运行原型 / 核心玩法验证。尚非正式发行版本。

## 核心玩法

1. 从左侧或右侧炮台发射弹珠，两座炮台共用弹珠选择。
2. 点击飞行中的弹珠，使它停留在当前位置；再次点击可以解除定身。
3. 发射另一颗弹珠，主动撞击定身球。
4. 不同属性的弹珠相撞会触发不同元素共鸣。
5. 利用碰撞、反弹、定身和元素效果解决场景中的机关与敌人。

## 技术结构

这是原生微信小游戏工程（`compileType: game`），使用 Canvas 绘制，不是 WebView 包装的普通小程序页面。

- `game.js`：小游戏入口、Canvas 适配、触摸事件映射和游戏逻辑
- `game.json`：小游戏运行方向与基础配置
- `project.config.json`：微信开发者工具项目配置

当前 Canvas 画面使用程序绘制，暂不依赖外部图片资源。

## 本地运行

1. 安装并打开[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「小游戏」项目类型。
3. 导入本仓库目录。
4. 将 `project.config.json` 中的 `touristappid` 替换为自己的小游戏 AppID（正式真机预览和发布需要）。
5. 点击「编译」，在模拟器中体验。

## 操作

- 点击底部弹珠卡片：选择当前弹珠。
- 在左侧或右侧炮台附近按住并向反方向拖动：瞄准。
- 松开：发射。
- 点击飞行中的弹珠：在空中定身。
- 点击定身弹珠：解除定身。
- 再发射一颗弹珠并撞击定身球：触发元素组合。

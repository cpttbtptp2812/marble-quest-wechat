# Marble Quest · 原生微信小游戏

本仓库是可直接由**微信开发者工具**导入的原生小游戏工程，不需要 Cocos Creator、npm install 或额外构建步骤。

## 运行

1. 下载/克隆整个仓库。
2. 打开微信开发者工具，选择「小游戏」项目。
3. 项目目录选择仓库根目录（能直接看到 `game.js`、`game.json`、`project.config.json`）。
4. AppID 使用自己的小游戏 AppID；仅体验时可按开发者工具提供的测试选项操作。
5. 点击编译。

## 操作

- 在场地左右区域按住拖动，松开发射弹珠。
- 点击底部元素卡切换弹珠类型。
- 点击飞行中的弹珠可定身，再次点击可解除。
- 两颗弹珠相撞会触发共鸣并短暂打开 Boss 护盾。
- 点击右下角重新开始。

## 技术

- 微信小游戏原生 Canvas 与触摸 API。
- 单一 `game.js` 入口，不经过 WebView、小程序页面或 Cocos 构建。
- 当前为可运行玩法原型；碰撞和物理采用轻量自研循环，后续可替换为 Box2D 等物理库。
